**Description** (each line its own paragraph)

```
All your desktops and every column, at once. A Niri-style overview effect for KWin, made for the Karousel scrollable tiling script: every virtual desktop as a zoomed-out strip of its windows, including the columns scrolled off-screen.

The whole layout in view: pan a strip and Karousel's real view scrolls along, so you land where you looked.

Rearrange by dragging: move a window to another desktop, stack it onto another window, put it above or below in a column or give it a column of its own; move whole columns; drop it between desktops for a new one.

Type to find: the current desktop's windows, with KRunner's results and apps in the same panel.

Keys and gestures: Meta+Ctrl+O, a screen edge or a touchpad swipe; arrow keys between windows and desktops, and Karousel's own key bindings keep working.

Desktops that come and go: create, rename and remove them in place; optionally, as GNOME's dynamic workspaces, the ones made in the overview go again once they're empty.

Requires Karousel: https://github.com/peterfajdiga/karousel

Enable it in System Settings > Desktop Effects. After an update, restart KWin (or log out and back in).

Source, issues and the full README: https://github.com/divinae/karousel-overview

Support: https://ko-fi.com/divinae4535
Made with AI: most of the code is written with Claude, Anthropic's AI assistant. I decide what goes in and review every change before a release.
```
